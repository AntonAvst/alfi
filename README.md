# Alfi 
## Desktop Finanacial Tracker
### By: Anton Avstreikh

This is a personal on going project, created because all of the existing tracker are not able to integrate with the kibutz payment system.
It's a finanacial tracker where you can upload your finanacial statments - bank, credit card or kibutz. 
The tracker will created a local database and summaraize to a monthly and yearly summary.
